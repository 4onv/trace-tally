Activity is evidence, not a quality score.

Tool outcomes describe the trace, not whether the user's task was solved. Runs can have different goals, environments, or workloads. Durations sum across known calls, may overlap, and are not wall-clock runtime. Missing durations remain unknown; no token usage or monetary cost is inferred.

Less data to share. Still worth reviewing.

Only fixed categories, status values, numeric counts, and relative durations enter this file. Metadata itself can reveal activity patterns. Review before sharing. This report contains no external assets, network requests, transcript bodies, or original identifiers.
